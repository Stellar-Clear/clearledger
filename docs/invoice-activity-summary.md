# Printable invoice activity summary

The invoice detail view can be printed from the browser (`Ctrl/Cmd+P`). The printable view contains the stated terms, current indexed lifecycle status, and Stellar transaction references when the indexer provides them. Transaction hashes are links to the configured Testnet explorer; an absent hash is shown as “not indexed yet”.

This summary reports indexed chain observations only. It does not verify off-chain documents, wallet ownership, or financing outcomes.
