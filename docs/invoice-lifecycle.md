# Invoice lifecycle in the app

Issuers register their profile, create an invoice, and wait for the indexer to show it as listed. Buyers can review the stated terms and fund listed invoices from the marketplace after connecting a wallet and completing the required verification and attestation steps. Lifecycle updates appear after Soroban events are indexed, so a transaction can remain pending briefly.

The profile and invoice screens use Testnet settings from the environment. A listed or funded status describes the indexed contract event; it is not an assertion that an off-chain document was verified or that returns are guaranteed.
